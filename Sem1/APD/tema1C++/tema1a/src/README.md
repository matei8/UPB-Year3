Map-Reduce Paradigm in C++
----------------

This project implements a **MapReduce** system using multithreading in C++. The program processes a set of input text 
files to analyze and categorize words alphabetically by their starting character. It uses a specified number of **mappers** 
and **reducers** to divide the workload efficiently.

### Features:

1.  **Mapper Threads:** Extract unique words from input files and categorize them into intermediate maps.

2.  **Reducer Threads:** Aggregate and sort words alphabetically, save results into output files.

3.  **Synchronization:** Ensures safe multithreaded operations using **mutexes** and **barriers**.


How It Works
------------

### 1\. Input Files

The program processes a list of input files provided in an input file as argument to the executable. Each file contains 
text that the mappers analyze to extract unique words.

### 2\. Multithreading Design

*   **Mappers:** Parse input files assigned to them, extract unique words, and store them in a shared map.

*   **Reducers:** Aggregate words categorized by their starting character from the mapper output, sort them, and write 
results to individual files (a.txt, b.txt, etc.).


### 3\. Output

The program generates one output file for each alphabet character (a.txt, b.txt, ..., z.txt). Each file contains:

*   Words starting with the corresponding letter.

*   Word frequencies and their originating file indices.

Code Explanation
----------------

### Main Components

1.  **Mapper Function (mapper)**

    *   Reads the files assigned to it by the following code providing start and end indices.

    ```cpp
    int filesPerMapper = filesNo / mapNo;
    int remainder = filesNo % mapNo;
    int start = mapperID * filesPerMapper + min(mapperID, remainder);
    int end = start + filesPerMapper + (mapperID < remainder ? 1 : 0);
    ```
    This way each mapper gets assigned a number of files to process. Moreover, it ensures that two different mapper threads
    won't access the same file at the same time from the files vector:
    
    ```cpp
     struct File {
        string fileName;
        int fileID;
        int status;
     };
     vector<File> files;
    ```

    *   Extracts unique words, converts them to lowercase, and removes non-alphabetic characters.

    *   Stores words in a local map and updates the shared maps variable. This is done in order to minimize the use of mutexes
    and at the same time to avoid a larger critical zone for each mapper thread. It ensures that each thread doesn't wait
    too much after other threads and can start working earlier in the process.
    
    ```cpp
    pthread_mutex_lock(&mutex);
    (*maps)[i] = std::move(localMap);
    inputFiles[i].status = 1;       /** 1 means that the file has been processed **/
    pthread_mutex_unlock(&mutex);
    ```

2.  ### Reducer Function (reduce)
    * The function calculates the range of characters (from a to z) that each reducer is responsible for processing. 
    This ensures that reducers work on non-overlapping portions of the alphabet.

    ```cpp
    int totalChars = 26;
    int charsPerReducer = totalChars / redNo;
    int remainder = totalChars % redNo;
    char startChar = 'a' + reducerID * charsPerReducer + min(reducerID, remainder);
    char endChar = startChar + charsPerReducer + (reducerID < remainder ? 1 : 0) - 1;
    ```

   * For example: If there are 2 reducers, Reducer 0 handles a-m and Reducer 1 handles n-z.

* The reducer iterates through the shared maps generated by mappers. It checks each word's starting character and 
 groups the words into a local structure, `localReductions`.

    ```cpp
    map<char, map<string, vector<int>>> localReductions;
    for (char currentChar = startChar; currentChar <= endChar; ++currentChar) {
        for (const auto &[mapID, currentMap] : *maps) {
            for (const auto &[_, word] : currentMap) {
                if (word[0] == currentChar) {
                    localReductions[currentChar][word].push_back(mapID);
                }
            }
        }
    }
    ```

   Here:

    * `localReductions` groups words by their starting character.

    *    Each word is associated with the IDs of files where it appeared.
    *    Words are sorted first by their frequency (in descending order) and then lexicographically (in ascending order).

    ```cpp
    for (auto &[currentChar, wordsMap] : localReductions) {
        for (auto &[word, mapIDs] : wordsMap) {
            sort(mapIDs.begin(), mapIDs.end());
        }
    }
    ```
   *   A barrier ensures that all reducers finish their processing before they begin writing the results to output files.

    ```cpp
    pthread_barrier_wait(&barrierReducer);
    ```
    *   For each character the reducer is responsible for, it writes the grouped and sorted words into a file named 
    `<character>.txt`.

    ```cpp
    for (char currentChar = startChar; currentChar <= endChar; ++currentChar) {
        string outputFileName = string(1, currentChar) + ".txt";
        ofstream outputFile(outputFileName);

        if (localReductions.find(currentChar) != localReductions.end()) {
            vector<pair<string, vector<int>>> words(
                localReductions[currentChar].begin(),
                localReductions[currentChar].end()
            );

            sort(words.begin(), words.end(), [](const auto &a, const auto &b) {
                if (a.second.size() != b.second.size()) {
                    return a.second.size() > b.second.size();
                }
                return a.first < b.first;
            });

            for (const auto &[word, mapIDs] : words) {
                outputFile << word << ":[";
                for (size_t i = 0; i < mapIDs.size(); ++i) {
                    outputFile << mapIDs[i] + 1;
                    if (i != mapIDs.size() - 1) {
                        outputFile << " ";
                    }
                }
                outputFile << "]\n";
            }
        }

        outputFile.close();
    }
    ```
3.  **Thread Controller (func)**

    *   Determines if a thread should act as a mapper or reducer based on its index.

    *   Calls either the mapper or reducer function, each with their special arguments, based on they need inside the function.

    ```cpp
    struct mapperArgs {
        int filesNo;
        vector<File> *inputFiles;
        int mapperID;
        int mapNo;
        map<int, map<int, string>> *maps;
    };
    
    struct reducerArgs {
        int reducerID;
        int redNo;
        map<int, map<int, string>> *maps;
    };
    ```

4.  **Synchronization**

    *   **Mutex:** Ensures only one thread modifies shared data (maps) at a time.

    *   **Barriers:** Synchronizes threads to ensure all mappers finish before reducers begin.
